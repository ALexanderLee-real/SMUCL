SMUCL 上海海事大学 Minecraft 启动器  v1.4.2
================================================

【怎么启动】
  1. 双击桌面上的「SMUCL」快捷方式
  2. 或直接双击本文件夹里的 SMUCL.exe

【文件夹说明】
  SMUCL.exe               主程序（勿单独复制走，必须和同目录文件在一起）
  resources\app\          程序本体（界面、核心逻辑）
  源码\                   完整工程源码，含 README.md、构建脚本与依赖
  debug.log               早期单独复制 exe 运行失败留下的日志，可直接删除

【数据保存在哪】
  配置：%APPDATA%\SMUCL\smucl-config.json
  游戏目录：默认 C:\Survaetr\PCL\.minecraft（与 PCL 共用，新版本会装在这里）
  存档：读取上述目录及其实例内的 saves，11 个存档共约 4.3 GB

【已知情况】
  · 本机当前 Chromium 沙箱异常，GPU 进程会反复崩溃。
    启动器已自动切换到「GPU 兼容模式」（等价于 --no-sandbox）来保证可用；
    重启电脑后可到「设置 → GPU 兼容模式」关闭它再试，正常后无需再开。
  · 目前为离线账户登录，适合单机与离线服务器，不能进正版验证服。
  · 下载页只列原版版本；NeoForge 等实例由 PCL 生成，SMUCL 负责启动。

【出错怎么办】
  1. 关闭启动器，删除 %APPDATA%\SMUCL\ 下的 GPUCache、ShaderCache 文件夹后重试
  2. 仍不行：设置里勾选「GPU 兼容模式」，重启启动器
  3. 还不行：重启电脑后重试

【主题与更新】
  · 主题：标题栏右上角的图标可一键切换深/浅色；也可以在「设置 → 外观」里选择跟随系统。
  · 更新：启动时会自动检查 GitHub 上的新版本，弹窗确认后只需下载约 340 KB 的应用代码，
    替换完成后自动重启；每次升级后首次启动会弹出更新日志。
  · 也可以在「设置 → 关于」里手动点「检查更新」。

【导入整合包】
  · 版本管理页 → 「导入整合包」→ 选 zip（PCL / HMCL 导出的整合包）
  · 会先显示包里的游戏版本、加载器、模组数量和导入位置，确认后才写入
  · 同名实例会自动改名为 xxx-imported，不会覆盖你原有的版本
  · 导出包通常不含公共库（libraries），导入后会提示缺多少个；
    用 PCL 打开一次该实例会自动补齐，或者重新下载对应版本
  · CurseForge / Modrinth 的清单包只有模组列表，需要在线装加载器，暂不支持

【安装模组加载器】
  · 下载页顶部「安装模组加载器」：选加载器 → 选游戏版本 → 选加载器版本 → 安装
  · Fabric / Quilt：直接下载版本 JSON 与依赖库，几十秒完成，不需要 Java
  · Forge / NeoForge：下载官方安装器并调用本机 Java 执行，首次需要几分钟
  · 底座原版没装时会自动先补装，装完在「版本管理」里就能看到新实例
  · 右上角「镜像加速 / 官方源」同样作用于加载器：镜像源更快，官方源在部分网络
    会被 DNS 污染（NeoForge 尤其明显），默认建议用镜像
